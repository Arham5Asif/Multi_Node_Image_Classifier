# Multi-Node Image Classifier — Project Root

Folder structure mirrors your FYP pipeline diagram (Week 1 → Week 10).
Open this whole folder as your VS Code workspace.

```
Multi_Node_Image_Classifier/

├── 01_ai_fundamentals/            # Week 1-2 — DONE (ResNet50 by you)
│   ├── datasets/                  # raw / preprocessed dataset splits

│   ├── shared/                    # schemas.py — single source of truth for both sides
│   ├── test_data/                 # sample images for local testing
│   ├── test_client.py
│   ├── run_local_demo.sh
│   ├── requirements.txt
│   └── README.md

├── 03_model_deployment/           # Week 5-6 — deploy best model to workers,

│
├── 05_dashboard/                  # Week 8 — monitoring dashboard
│   ├── backend/                   # Flask/FastAPI routes serving worker + job data
```

## Getting started in VS Code

1. Open this folder (`Multi_Node_Image_Classifier/`) as your workspace.
2. `cd 02_distributed_system && pip install -r requirements.txt`
3. See `02_distributed_system/README.md` for how to run the master + workers.
